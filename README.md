# Task 1: Harmonization
To solve this task, I first investigated the different datasets. The datasets contain census data about 8.5 million individuals. Looking at the handicaps column, only about 36,000 entries contain data (after removing NAs and values that only contain dashes), where 4,872 distinct values can be found. The 1801 census seems to only contain sex data indicated by “k” or “m”. Looking at the others, the column also contains data about jobs and other information along with handicaps. I decided to extract single words and count their occurrences across the different datasets. I tried simple standardization by looking at the top 20 words across all censuses and selecting those that resemble handicaps to see how many rows I could label. The results are in handicaps_results.txt and handicaps_std.csv, along with CSV files containing the word counts.

# Task 2: Linking
To solve this task, I splited the dataset into the two censuses. My first thought was to compare the individuals from one census to the other, but comparing all individuals would be computationally inefficient. I decided to block on year born, sex, and the first letter of the name. This resulted in about 1.2 M possible pairs. I then scored each pair by comparing the full name, birthplace, and event place (by Fuzzy Scoring); and marital status and free/enslaved flag (by exact match). I assigned a specific weight to each attribute to calculate a composite score from 0 to 100. After looking at the results, I set a threshold of 85 points to declare a match between the two censuses, yielding about 33,500 matches. Some individuals might have more than one match, which is an area for future refinement.

Note: The Fuzzy Scoring approach was implemented based on an idea from Google Gemini.
